# Growth Funnel & Activation Audit Process

**Purpose:** Evaluate conversion and activation flows from first visit to first value in-app.

**Status:** Active.

---

## 1. Scope

Audit:

- Public pricing/landing conversion UX
- Sign-up/sign-in flow continuity
- First-session onboarding activation
- Core value path (first property, first analysis/model)
- Upgrade path clarity and confidence

Reference docs:

- `docs/policies/design-spec.md`
- `docs/reference/roadmap.md`
- `docs/audits/feature/`

---

## 2. Audit dimensions

- Funnel friction and drop-off risks
- CTA hierarchy and messaging clarity
- Time-to-first-value
- Trust and objection handling
- Upgrade triggers and plan clarity

---

## 3. Output

Write report to:

- `docs/audits/growth-funnel/YYYY-MM-DD-growth-funnel-audit.md`

Use the shared report template in `docs/process/audit-report-template.md`.

---

## 4. Execution

1. Audit primary acquisition and activation flows.
2. Identify friction points and conversion blockers.
3. Prioritize high-impact, low-effort improvements.
4. Recommend measurable funnel hypotheses.
5. Audit only; no code changes.
