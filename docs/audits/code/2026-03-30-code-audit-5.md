## Severity-ranked findings

### High

- **Strict TypeScript check fails — `HTMLAsideElement` not in scope** — `npx tsc --noEmit` (from `app/`) reports `TS2552: Cannot find name 'HTMLAsideElement'. Did you mean 'HTMLBaseElement'?` at `app/app/(app)/app-layout-client.tsx` line **137** (`const drawerPanelRef = useRef<HTMLAsideElement>(null);`). In the project’s TypeScript `lib.dom.d.ts`, the `HTMLElementTagNameMap` entry for `"aside"` is `HTMLElement`, not a distinct `HTMLAsideElement` interface — so the identifier is invalid for a global ref type. **Impact:** Any CI or local workflow that runs `tsc --noEmit` (or `next build` with typecheck) may fail until the ref type uses `HTMLElement`, `React.ElementRef<'aside'>`, or an explicit cast.

- **Oversized client modules — maintainability and regression risk** — Several surfaces remain far above the process guideline (~300 lines) and bundle many concerns: `app/app/(app)/analyze/deal-analyzer-form.tsx` (~**1306** lines per line count), `app/app/(app)/properties/add-property-wizard.tsx` (~**1591** lines), `app/app/(app)/properties/property-form.tsx` (~**1027** lines). *Note:* Run 4 also flagged long mortgage/projection tab files; deep-linking to `/mortgage` and `/modeling` with dynamic tab imports mitigates chart bundle cost but file size remains high for review and conflicts.
