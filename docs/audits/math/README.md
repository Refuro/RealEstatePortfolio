# Math & Logic Audits

This folder contains periodic Math & Logic audit reports. Each report verifies correctness of math-heavy logic: amortization, payoff projections, property/portfolio metrics, and benchmarks.

## Process

1. Run a math audit: say **"run math audit"** or **"math audit"** in chat. The agent follows [docs/process/math-logic-audit.md](../../process/math-logic-audit.md) and writes a report here.
2. Review the report. Filenames are `YYYY-MM-DD-math-logic-audit.md`.
3. If you want fixes, create tasks in [docs/tasks.md](../../tasks.md) from the findings. The builder can then implement them.

## Reports

Audit reports are added here with dated filenames (`YYYY-MM-DD-math-logic-audit.md`).
