# Veld Portfolio

Lightweight SaaS for small real estate investors (1–20 properties) to track portfolio performance, analyze returns, and understand their investment position.

- **Documentation:** [docs/](docs/) — product spec and engineering backlog
- **Application:** [app/](app/) — Next.js app (run from here for local dev and deploy)

## Quick start

```bash
cd app
cp .env.example .env
npm install
npm run dev
```

See [docs/setup.md](docs/setup.md) and [app/README.md](app/README.md) for full setup and deployment.
