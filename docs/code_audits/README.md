# Code Audits

This folder contains periodic code audit reports. Each report is a snapshot of the codebase health across design compliance, architecture, efficiency, technical debt, security, and the product mantra.

## Process

1. Run a code audit: say **"run code audit"** or **"code audit"** in chat. The agent follows `docs/code-audit-process.md` and writes a report here.
2. Review the report. Filenames are `YYYY-MM-DD-code-audit.md`.
3. If you want fixes, create tasks in `docs/tasks.md` from the findings. The builder can then implement them.

## Reports

Audit reports are added here with dated filenames. No reports until the first audit is run.
