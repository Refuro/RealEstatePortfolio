# Security & Privacy Audits

This folder contains periodic security and privacy audit reports.

## Process

1. Run: **"run security audit"**.
2. Agent follows [docs/process/security-audit-process.md](../../process/security-audit-process.md).
3. Reports are written here as `YYYY-MM-DD-security-audit.md`.

## Reports

Use this folder for formal security lane reports. Historical security notes may exist under `docs/security/`.
