# Code Audit — 2026-03-28 (run 2)

## Executive summary

- **Overall:** The `app/` tree follows a clear UI → API → `lib/` → Prisma layering; plan limits and metrics are centralized (`lib/plans.ts`, `lib/metrics/`). Charts use `next/dynamic` with `ssr: false` and loading placeholders where expected (`dashboard-charts.tsx`, amortization chart).
- **Top risks:** Some app surfaces remain very large (e.g. property mortgage tab) which increases review cost and regression risk; `next.config.ts` CSP still allows `'unsafe-inline'` / `'unsafe-eval'` on `script-src` (documented tradeoff for Next/Clerk but worth tracking).
- **Recommendation:** Prefer extracting subcomponents and shared hooks from mega-files in the next refactor pass; keep API routes thin (already mostly true).

## Severity-ranked findings

### Critical

- None observed in this pass.

### High

- **Large client modules** — Maintainability / review burden — `app/app/(app)/properties/[id]/mortgage-tab-content.tsx` is very large (800+ lines). Same pattern increases merge conflict risk and makes behavior changes harder to test in isolation.

### Medium

- **CSP string tradeoffs** — Security posture — `app/next.config.ts` builds a baseline CSP with `script-src 'self' 'unsafe-inline' 'unsafe-eval'`. Common for Next.js apps but weakens XSS defense-in-depth; enforcement is gated by `CSP_ENFORCEMENT` (report-only by default).

- **Auth proxy public route list** — Operational correctness — `app/proxy.ts` does not list `/api/csp-report` as public. Browser-sent CSP reports for unauthenticated sessions may fail Clerk `auth.protect()`, reducing visibility into violations on public pages (see Security lane).

### Low

- **Sentry placeholder defaults** — Ops noise — `withSentryConfig` uses placeholder org/project when env unset; acceptable for local dev, ensure production env is set.

## Risk & impact assessment

Unresolved large-file debt mainly affects **velocity and defect rate**, not immediate user-facing failure. CSP/report-uri behavior gaps affect **security telemetry** more than end-user auth.
